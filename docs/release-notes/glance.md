# Glance

Open Glance from the Crona menu, or assign Toggle Glance in Settings > Shortcuts. Glance covers the display containing the pointer and leaves other displays untouched. Press the shortcut again, Escape, Close, or the background to return to your previous app.

Glance shows the current session, issues and habits for the selected day, today’s focus time across contexts, and quick capture. Start focus using an issue or Quick Session, with stopwatch, timer, and Pomodoro setup inline. Capture accepts one issue per line and the same #repo/stream notation as Crona’s existing capture flow. Review the proposals before importing.

Successful focus starts and imports dismiss Glance. Pause/resume and simple habit completion leave it open. Duration-based habit logging and ending a session use the existing Crona flows. Unfinished Glance drafts survive dismissal until the app exits and remain separate from menu drafts.

Glance uses native Liquid Glass on supported macOS releases and material fallbacks otherwise. Its daily layout shows complete independently scrollable issue and habit lists alongside a score calendar, selection preview, and day summary. Selecting a calendar date updates all day panes; past dates are read-only. The active session stays live above the browsed day. Blocking timer prompts dismiss Glance.

Glance shares the menu popup’s date pill, issue rows, and habit rows, including visible action buttons. Content reserves space for the menu bar, notch, and Dock, while the overlay backdrop remains fullscreen. Empty issue sections use a compact pane.

## Persistent, centered workflows

Glance remains open after creating or editing work, importing capture, starting focus, and ending sessions. Editors, confirmations, tags, dates, and manual-session forms appear centered over Glance using the existing feature drafts. Close or cancel the form to return to the overview. Escape closes the active form first; only an explicit Close, toggle shortcut, or Escape on the overview closes Glance. Background clicks do nothing.

Break screens and timer prompts appear above Glance without dismissing it. Relevant global shortcuts use Glance while it is visible, and the menu popup stays hidden to avoid duplicate copies of a draft.
