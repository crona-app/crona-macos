# Crona for macOS v1.1.0-beta.6

This beta makes Glance self-contained and improves popup sizing and transitions.

## Glance stays open

- Creating or editing issues, importing capture, starting focus, and ending sessions keep Glance open.
- Issue and habit editors, tags, due dates, manual-session forms, confirmations, and end-session flows open centered over Glance instead of handing off to the menu popup.
- Existing menu drafts can be shown in Glance without losing their input or opening a second interactive copy.
- Escape closes the active editor first. Close, the toggle shortcut, or Escape on the overview closes Glance; background clicks do nothing.
- Break screens and blocking timer prompts leave Glance underneath, and habit actions use Glance’s selected date.

## Better-fitting popups

- Menu popup windows and Glance dialogs fit their content, with scrolling for longer forms and details.
- Menu windows resize smoothly around a stable top edge. Hosted dialogs share one outer background so overlapping glass surfaces do not resize independently.
- Window captures no longer include the old invisible area below a short popup.
- Habit detail actions have dedicated footer space, preventing history text from overlapping the buttons.

## Reliability

- Glance stays visible when another utility, such as screenshot capture, takes focus.
- Unexpectedly hidden windows no longer leave a stale Glance state that blocks the menu popup.

Requires a Crona daemon compatible with protocol **1.7**, unchanged from beta.5.
