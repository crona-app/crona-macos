# Peek

Open Peek from the Crona menu, or assign Toggle Peek in Settings > Shortcuts. Peek covers the display containing the pointer and leaves other displays untouched. Press the shortcut again, Escape, Close, or the background to return to your previous app.

Peek shows the current session, issues and habits for the selected day, today’s focus time across contexts, and quick capture. Start focus using an issue or Quick Session, with stopwatch, timer, and Pomodoro setup inline. Capture accepts one issue per line and the same #repo/stream notation as Crona’s existing capture flow. Review the proposals before importing.

Successful focus starts and imports dismiss Peek. Pause/resume and simple habit completion leave it open. Duration-based habit logging and ending a session use the existing Crona flows. Unfinished Peek drafts survive dismissal until the app exits and remain separate from menu drafts.

Peek uses native Liquid Glass on supported macOS releases and material fallbacks otherwise. Its daily layout shows complete independently scrollable issue and habit lists alongside a score calendar, selection preview, and day summary. Selecting a calendar date updates all day panes; past dates are read-only. The active session stays live above the browsed day. Blocking timer prompts dismiss Peek.

Peek shares the menu popup’s date pill, issue rows, and habit rows, including visible action buttons. Content reserves space for the menu bar, notch, and Dock, while the overlay backdrop remains fullscreen. Empty issue sections use a compact pane.
