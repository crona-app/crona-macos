# Global shortcuts

Configure shortcuts in Settings > Shortcuts to open Crona, create an issue, prepare a focus session, pause or resume a stopwatch session, end a session, or open Settings from any app.

New actions start unassigned. Your existing Open Settings shortcut is preserved. Use Command, Control, or Option with a key; Shift can be included. Conflicting bindings display an error and keep the previous assignment.

Crona must be running. When its menu bar icon is hidden, interface shortcuts open a centered popup on the screen containing the pointer. Start Focus opens setup for confirmation. Open drafts and editors are preserved. Pause / Resume reports the result without taking keyboard focus.
