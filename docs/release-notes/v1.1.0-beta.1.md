# Crona for macOS v1.1.0-beta.1

The first 1.1.0 beta brings ad hoc focus sessions to the Mac app and refines the menu-bar popup and floating timer.

## Focus without an issue

Start a Stopwatch, Pomodoro, or Timer session without choosing an issue first. When you finish, attach the work to an eligible issue, create a new issue, or keep it as ad hoc. Add a session summary to record what you completed.

The completion workflow is available from the menu-bar popup, floating timer, and timer alerts. If completion needs a retry after creating an issue, Crona retains that issue rather than creating another one.

## A clearer popup

- Forms replace the dashboard cleanly, without stacked glass, dark scrims, or focus remaining on background controls.
- Issue and habit creation use consistent destination pickers and primary actions, clearer required fields, and improved keyboard focus.
- Stats uses subtle borders to separate metrics, focus balance, issues, and habits, while keeping the focus score prominent.
- Wellbeing labels are easier to read, and shared controls better respect accessibility preferences.
- Focus sessions and Away mode continue to gate access to other tabs.

## A minimal progress background

Enable **Progress Background** in **Settings → Menu Bar → Floating Timer** to show a faint neutral fill behind Pomodoro and Timer sessions. The fill tracks the current segment with smooth 50 ms updates. Stopwatch stays unchanged, and Reduce Motion uses stepped updates. A Settings preview shows the treatment before you enable it.

## Reliability fixes

- Editing an unscheduled issue preserves its scheduling state; you can also choose no date.
- New issues default to the daemon's logical day.
- Issue submission stays disabled through refresh and follow-up actions to prevent duplicates.
- Create & Focus is disabled during an active session.
- Daily totals and Stats refresh when another client changes session history.
- Submitting an empty session summary moves focus to the required field.

## Compatibility

- Release tag: `v1.1.0-beta.1`.
- Apple marketing version: `1.1.0`; build: `19`.
- Semantic release version: `1.1.0-beta.1`; channel: `beta`.
- Requires a Crona daemon reporting protocol `1.6`. Update the core daemon before using this beta with a `1.5` installation.
