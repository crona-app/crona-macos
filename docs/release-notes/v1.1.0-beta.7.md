# Crona for macOS v1.1.0-beta.7

This beta adds Glance customization, an expandable timer HUD, and controls for where shortcut popups open. It also reduces retained UI and background data work.

## Make Glance yours

- Choose visible widgets in Settings > Glance or the centered Customize Glance panel.
- Reorder Issues and Habits in the main column, and Calendar, Selection, and Day Summary in the side column. A proportional preview shows the arrangement for your display.
- Choose the starting issue section, show only unfinished habits, or reopen on the last viewed date instead of Today.
- Hidden Selection widgets no longer prevent access to details: issue and habit details open centered over Glance, with browsing tied to Glance’s day and lists.
- Restore defaults at any time.

## Glance during a session

- Active sessions replace Issues, Habits, and Selection with the same timer, progress indicators, phase information, and session controls used by the menu popup.
- Calendar and Day Summary remain alongside the timer when enabled and space permits.
- Timer content is centered, and its card matches the supporting column’s height instead of stretching to fill the screen.
- Task editing, creation, capture, and new-session setup are unavailable while a session is active. Session controls remain accessible.

## Expand the timer HUD

- Use the dedicated Expand action beside the HUD’s hover controls to see the issue, repository and stream context, and description.
- The HUD widens and expands upward, keeping the running timer and session controls at the bottom. Pomodoro and countdown sessions show a progress bar.
- Collapse with the collapse button, Escape, or by moving focus elsewhere. Hover actions and dragging remain separate from expansion.
- End transitions directly from the expanded HUD into the completion form without first shrinking to the compact timer.

## Shortcut popup placement

- Choose Screen center or Menu bar in Settings > Shortcuts. Screen center is the default and uses the display containing your pointer.
- Centered popups stay centered as their content changes. Clicking the menu bar icon retains its usual anchored placement.
- When the menu bar icon is hidden, shortcut popups open in the center.
- Shortcuts settings have clearer grouping, larger text, and more spacing.

## Less retained UI and background work

- Create the menu popup on first use and release Library window content when it closes, preserving navigation and window placement.
- Suspend Glance’s automatic data refreshes while it is closed and discard its cached day data.
- Batch stats refresh events and retain three recently used calendar months, plus today and the selected day.
- Load HUD descriptions from cached issue data first, using a stream-scoped lookup when needed instead of fetching every issue.

Requires a Crona daemon compatible with protocol **1.7**, unchanged from beta.6.
