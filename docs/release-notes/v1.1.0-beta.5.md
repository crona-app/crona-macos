# Crona for macOS v1.1.0-beta.5

This beta adds Glance, a fullscreen overlay for your day, configurable global shortcuts, and simpler timer setup and time entry.

## Glance

Open Glance from the Crona menu, or assign Toggle Glance in Settings > Shortcuts. It covers the display containing the pointer and shows issues, habits, a score calendar, a selection preview, and the day summary in one view. Press the shortcut again, Escape, Close, or the background to return to your previous app.

- Start focus from an issue or as a Quick Session, with stopwatch, timer, and Pomodoro setup in a card that matches the menu.
- Capture issues with the same `#repo/stream` notation and autocomplete as the menu, then review proposals before importing.
- Select a date on the calendar to browse any day. Past days are read-only, and the active session stays live above them.
- Issue and habit rows are the same as the menu's, and clicking anywhere on a row selects it.
- Glance blurs the content behind it and leaves other displays untouched. Blocking timer prompts dismiss it.

Unfinished Glance drafts survive dismissal until the app exits and stay separate from menu drafts.

## Global shortcuts

Configure shortcuts in Settings > Shortcuts for Show Crona, Create Issue, Start Focus Session, Pause / Resume Session, End Session, and Open Settings. Your existing Open Settings binding is preserved; new actions start unassigned. Shortcuts also work with the menu bar icon hidden.

## Simpler timers and time entry

- Sessions started without an issue are called Quick Sessions everywhere.
- Timer setup uses directly editable duration and cycle fields with compact presets and a fixed start action.
- Check-in and manual-session durations use hour/minute inputs, and sleep scores accept direct entry from 0 to 100.
- Targets, estimates, timer presets, and edit fields share one hour/minute notation.

## Fixes

- A confirmed break deferral shows a brief confirmation instead of the pointer countdown.
- An omitted daily plan shows the normal empty state instead of a decoding error.
- Late habit refreshes for a previously selected day are ignored.
- Issue and habit details no longer draw an extra band behind the footer buttons.

Requires a Crona daemon compatible with protocol **1.7**, unchanged from the previous beta.
