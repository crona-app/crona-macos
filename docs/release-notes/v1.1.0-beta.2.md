# Crona for macOS v1.1.0-beta.2

The second 1.1.0 beta brings the new core planning features to the menu bar: the delay penalty, carry-over, tags, and bulk issue capture with an Inbox. It also reworks the Issues tab around a shared day and Planned, Overdue, and Upcoming sections.

## One day across the popup

The day pill now moves the Issues, Habits, Wellbeing, and Stats tabs together, and stops at today. The Issues tab splits that day into **Planned**, **Overdue**, and **Upcoming**, matching the TUI, with pinned issues first. The day pill and section switch stay put while only the issue list scrolls, and **Start Ad Hoc** sits below the list.

## Delay penalty

Issues the core marks as high risk show a red **High risk** marker in the Issues tab, with the delay explained in issue details and on hover. Stats counts high-risk issues for today.

## Carry-over

- Issues carried to a later day show a lavender **Carried ×N** badge, and issues that keep getting carried show **Stalled**. Hover the badge for where it came from and how often it moved.
- **Carry to Tomorrow** in the row menu moves an unfinished issue to the next working day, with a short **Undo**. Past days keep the issues they carried away, marked **Carried**, and offer **Undo Carry**.
- Issue details show the carry and stall history.

## Capture and the Inbox

- The new capture button beside **Start Ad Hoc** opens a sheet for pasting several `- ` lines at once. A live preview shows each issue's target, estimate, date, and tags, and lines the core cannot resolve block the import until they are fixed.
- Typing `#`, `~`, `@`, or `+` at the start of a word suggests a repo and stream, an estimate, a date, or a tag. Use the arrow keys and Return or Tab to insert one. Names with spaces are written with dashes, such as `#side-projects/blog-posts`.
- Untargeted issues land in the system **Inbox**, shown as a fourth **Inbox (N)** section when it has issues. **Move to** sends an Inbox issue to a real stream. The Inbox never appears in repo and stream pickers.

## Tags

- Issues and habits show their tags as small color dots beside the title; hover to see every tag. Details list all tags.
- A tag filter on the Issues and Habits tabs shows or hides tags, including **Untagged**. It shares its saved filter with the TUI, so changing it in either place updates the other.
- The issue and habit creators have a tag field that suggests existing tags as you type and offers **Add new tag** for new names. **Edit Tags…** in the row menu changes an existing item's tags.
- Stats adds **Focus by tag**: the top tags by focused time for the shown day or its week.

## Reliability

- Daemon requests no longer hang or crash the app when the socket closes mid-response.
- A malformed alert delivery is skipped instead of stopping alerts.
- Hover details wait briefly before opening, so scrolling the issue list does not flash popovers.

## Compatibility

- Release tag: `v1.1.0-beta.2`.
- Apple marketing version: `1.1.0`; build: `20`.
- Semantic release version: `1.1.0-beta.2`; channel: `beta`.
- Requires a Crona daemon reporting protocol `1.7`. Update the core daemon before using this beta; a `1.6` daemon shows a protocol mismatch.
